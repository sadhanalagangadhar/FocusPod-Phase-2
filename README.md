# FocusPod — Phase 2: AI Focus Coach

Phase 2 upgrades FocusBot with personalized, local productivity coaching.

## Features
- Includes the Phase 1 focus timer, tasks, goals, session history, insights, dark mode, and JSON export.
- Coach responses use saved tasks, high-priority tasks, the daily focus goal, today’s sessions, and recent focus minutes.
- Task breakdown, study/focus session planning, distraction reset, and progress review.
- Runs locally in the browser. No API key, paid AI service, server, or hardware is required.
- Uses the same browser storage key as Phase 1 so existing data in the same browser profile can remain available. Export a JSON backup before replacing or resetting project data.

## Run on Windows
1. Extract this ZIP.
2. Open the `FocusPod-Phase-2` folder.
3. Double-click `run.bat`, or open CMD in the folder and run `run.bat`.

## Important limitation
FocusBot uses local rule-based logic and app data; it is not connected to a generative cloud AI model. Accounts and cross-device cloud sync are not included.
